Xuất thông tin đơn từ hóa đơn GTGT (PDF / Hình ảnh)

Hệ thống tự động sử dụng Google Gemini API để đọc và phân tích cấu trúc nhiều hóa đơn PDF hoặc hình ảnh (PNG, JPG, WEBP) cùng lúc. Hỗ trợ dán trực tiếp từ clipboard.

Hỗ trợ .pdf, .png, .jpg, .jpeg, .webp, .bmp, .jfif (Dung lượng < 5MB/file)
Đang gửi dữ liệu hóa đơn và xử lý bằng AI...
